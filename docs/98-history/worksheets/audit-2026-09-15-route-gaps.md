## Worksheet integrity

- **Source rule**: every row traces to (a) a fix-round spec (bug→route), (b) a documented AGENT_LOGBOOK/AGENT_LOGBOOK audit finding, or (c) a logbook "VERIFY" note. No fabricated findings. Rows where the log lacks detail are `VERIFY-LIVE` and explicitly noted.
- **Statuses used**: `FIXED-in-this-round` = mapped bug fixed by B1/M1-M5/C1-C3/A6/A2/A5 in this round; `KNOWN-NOT-A-BUG` = documented resolution in a prior wave or a deliberate design/non-regression; `OPEN` = documented gap not addressed this round; `VERIFY-LIVE` = wire truth must be confirmed against a live stack before treating as fixed.
- **Doc-only task**: no code, migration, test, or config file changed. See `git status --short`.
