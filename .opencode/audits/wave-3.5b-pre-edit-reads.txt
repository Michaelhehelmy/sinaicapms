## READ 1 — backend/src/middleware/rateLimit.js (full file, 232 lines)

- `RATE_LIMIT_POLICIES` is a single ordered declarative table; first match wins;
  `default` (max 100, envKey `RATE_LIMIT_API`) covers everything unmatched.
- Existing entries: `POST /api/auth/pos-login` 15, `/api/auth/*` 30, `POST /api/tenants` 5/5m,
  `GET /api/tenants*` 60, `/api/admin*` 20, `/api/payments*` 20, `POST /api/pos/auth/login` 15,
  `POST /api/pos/auth/refresh` 30, `/api/pos/*` 60, `/api/leads` 10, `/api/contact` 10,
  `POST /api/feedback` 6, `POST /api/marketplace/reviews` 10/1m, `GET /api/orders/status/*` 5/1m,
  `POST /api/stream/token` 10/1m, `default` 100.
- `policyLimiter` compile: key regex `/^(GET|POST|PUT|DELETE|PATCH)\s+(.+)$/` (NOT HEAD);
  prefix = `pattern.endsWith('*')`, base = trailing-`*` stripped; hit = startsWith(base) or exact.
  No mid-path wildcard (`*` only at end). `default` is not compiled into entries (fallback limiter).
- `rateLimitMiddleware` skips when `ENVIRONMENT === 'test'`; keys on `cf-connecting-ip` only;
  optional `makeKey`; KV-backed when `RATE_LIMIT_KV && RATE_LIMIT_KV_ENABLED !== 'false'`
  (fail-closed), else in-memory map; per-request `envKey` dial via `readLimitInt`.
- `tenantAwareLimiter` (Wave 3.5): second `app.use()` after authed gates; key `t:{ip}:{tenantId}:{path}`;
  no-op unless `scope.user && scope.tenantId`.
- SSE `/api/stream/orders` exempted inside policyLimiter.

## READ 5 — Design note for 3.5b (from logbook fold 2026-09-20 WAVE 3.5)

- Deferred work: public per-group budgets (marketplace, onboarding, availability, media,
  meal-plans, Paymob webhook). **P1**: Paymob webhook shares the default 100/min IP bucket —
  busy NAT'd tenant IP would drop payment callbacks; needs a dedicated/exempt budget.
- So: add declaration-ordered policy entries ABOVE `default` for the six groups, each with its
  own envKey dial (matching the existing convention), and a dedicated budget for
  `POST /api/public/paymob/webhook`. Optional: extend the method regex to HEAD (media HEAD reads)
  and support mid-path `*` (meal-plans `/api/projects/*/meal-plans` shape) — both small, tested changes.
